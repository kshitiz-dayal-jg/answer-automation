# answer-automation

- [`automation/`](automation/) — Python automation service, managed with [uv](https://docs.astral.sh/uv/).
- [`admin-panel/`](admin-panel/) — Next.js admin panel (App Router, TypeScript, Tailwind CSS), managed with pnpm.

## Getting started

### automation

```bash
cd automation
uv sync
uv run automation
```

### admin-panel

```bash
cd admin-panel
pnpm install
pnpm dev
```
